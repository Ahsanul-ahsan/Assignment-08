# 🧱 Tiles Gallery

A modern web application to showcase a beautiful collection of tiles with authentication, dynamic routing, and a responsive UI built using Next.js App Router.

---

## 🚀 Live Demo
👉 https://your-live-site-link.vercel.app

---

## 📌 Project Purpose

The purpose of this project is to build a **Tiles Gallery platform** where users can:
- Browse tile collections
- View detailed information about each tile
- Register and login securely
- Manage their profile
- Experience a fully responsive modern UI

---

## ✨ Key Features

### 🏠 Home Page
- Hero banner with "Discover Your Perfect Aesthetic"
- Scrolling marquee for announcements
- Featured tiles section (Top 4 tiles from API)

### 🧱 Tiles Gallery
- Search tiles by title
- Dynamic tile listing from JSON/API
- Responsive grid layout
- View details button for each tile

### 🔍 Tile Details Page
- Large high-quality image preview
- Title, description, category, price
- Stock status indicator
- Clean UI with responsive design

### 🔐 Authentication System
- Email & Password login
- User registration system
- Google Social Login
- Secure session handling using BetterAuth
- Protected routes for private pages

### 👤 My Profile
- View logged-in user data
- Update name and profile image
- Protected route access

### 🎨 UI/UX
- Fully responsive (mobile, tablet, desktop)
- Clean and modern design
- Loading spinner for API calls
- Not-found page handling
